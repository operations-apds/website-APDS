# Asia Pacific Data — Website

Single-page marketing site for Asia Pacific Data, a horse racing data and services provider.

## Structure

```
asiapacificdata/
├── index.html          # Header, hero, About/What We Do, Our Approach, Capabilities carousel, Get in Touch, footer
├── css/
│   └── styles.css      # All styles (colour variables at the top)
├── js/
│   └── main.js         # Mobile nav, capabilities carousel, footer year, contact form
├── assets/
│   ├── images/         # Photos, hero imagery
│   └── icons/          # logo.svg (green, for light bg), logo-light.svg (for dark bg), favicon.svg
└── README.md
```

## Run locally

No build step. Open `index.html` in a browser, or serve it:

```
python3 -m http.server 8000
```
